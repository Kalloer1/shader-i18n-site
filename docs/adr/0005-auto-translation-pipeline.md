# 自动汉化流水线：下载 → 检测 → LLM 初翻 → 直接上线

汉化文件的生产由脚本流水线自动化：按下载量从高到低逐个从 Modrinth 下载光影最新版 zip → 检查 `shaders/lang/` 是否已有 `zh_CN.lang`（自带中文则标记排除并跳过）→ 取出 `en_US.lang` 交给智谱 GLM-4.7-flash 初翻（分块翻译、失败自动重试，该模型易中断）→ 用 `validate-lang` 校验键名/格式码/BOM → 存入 `site/public/lang/<光影id>/<光影版本>/` 并登记版本映射。**AI 初翻直接上线提供下载**，详情页醒目标注"未人工校对"；人工校对后以新 `langVersion` 覆盖登记。LLM key 一律走环境变量（`ZHIPU_API_KEY`），不入库。

首批只跑下载量前 50 个以验证流水线质量（占位符零错误、译文可读），确认后再放量全量。同步与流水线由 GitHub Actions 定时执行（ADR-0004 的目录每日刷新，流水线逐步扩大覆盖）。

## Considered Options

- 待人工校对后才上线：冷启动阶段站内长期空白，"有得用"优先于"完美"，被否决
- 一次性全量自动跑完：prompt 质量未经批量验证前可能批量返工，被否决
- 人工逐个校对后再发布：人力成本与站点规模不匹配，被否决
