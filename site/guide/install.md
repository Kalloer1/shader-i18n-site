# 安装教程

把汉化文件装进光影包只需三步，全程不需要解压光影 zip。

::: warning 前置条件
资源包/材质包**不能**替代本操作：Iris 与 OptiFine 只从光影包 zip 内部的 `shaders/lang/` 目录读取语言文件。
:::

## 第一步：下载汉化文件

在[光影列表](/)找到你正在使用的光影包，进入详情页，下载**与光影版本一致**的 `zh_CN.lang`。

## 第二步：注入光影 zip

1. 找到你的光影文件，位于 `.minecraft/shaderpacks/` 目录下的一个 zip（例如 `BSL_v8.4.zip`）。
2. 用压缩软件（7-Zip、WinRAR、Bandizip 等）**打开**这个 zip（不要解压）。
3. 进入 zip 内的 `shaders/lang/` 目录（没有就新建一个 `lang` 文件夹）。
4. 把下载的 `zh_CN.lang` 拖进去。

完成后 zip 内应有如下结构：

```
BSL_v8.4.zip
└── shaders/
    ├── lang/
    │   ├── en_US.lang   ← 光影自带
    │   └── zh_CN.lang   ← 你刚放进去的
    └── ...
```

## 第三步：进入游戏验证

1. `选项 → 视频设置 → 光影包`，选中该光影。
2. 确认游戏语言为**简体中文**。
3. 光影设置界面出现中文即成功。

## 常见问题

- **设置界面还是英文？** 检查汉化文件的光影版本是否与你下载的光影版本一致；旧版汉化在新版光影上会部分回退为英文。
- **光影界面完全没变化？** 确认 `zh_CN.lang` 位于 zip 内 `shaders/lang/` 下，而不是 zip 里又套了一层文件夹。
- **用的是解压过的光影文件夹？** 把 `zh_CN.lang` 放入该文件夹的 `shaders/lang/` 即可，效果相同。
